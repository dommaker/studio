## AC#4 证据：改动前后 spawn 命令逐字对照

一次性脚本把同一 task 分别喂 HEAD 版与改后版 `buildSessionCommand`（旧版按活路径补 `sessionFlags=''`、`addDirArgs` 不传），8 个代表形态输出**全部逐字相同**：

| 形态 | 结果 |
|------|:---:|
| claude 新建（无 session）／新建 + sessionId／续用／续用 + maxTurns | ≡ |
| kimi 续用／codex 新建／codex 续用／opencode 续用 | ≡ |

唯一差异出现在「有人手工往 `parameters` 里塞一串 claude flag」这个假设分支上（该键全仓零生产者，即票面判死证据）：

```
before: cd "/wt" && claude --print --output-format stream-json --verbose --continue < "/wt/.daemon/prompt.md" 2>&1
after : cd "/wt" && claude --print --output-format stream-json --verbose < "/wt/.daemon/prompt.md" 2>&1
```

机理与实测一致：被摘掉的两段拼接（`opts.addDirArgs ?? ''`、`opts.sessionFlags`）在活路径上恒为空串，且组装数组尾随 `.filter(Boolean)`，故命令形状等价。
