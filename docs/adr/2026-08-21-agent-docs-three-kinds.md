# Agent 文档内容三分：「入口文档」作废，拆为项目说明书 / 治理契约 / 本机运维簿（2026-08-21）

> 状态：**proposed**，待决策单冻结。来源：grilling 三轮开图（Q1-Q11 全裁决）+ 工具读取行为实证调研。
> 配套 ADR：[2026-08-21-agent-docs-placement-model.md](./2026-08-21-agent-docs-placement-model.md)（落点模型）。

## 背景

「入口文档」一词长期超载：CLAUDE.md / AGENTS.md 里混居着本质不同的内容，是所有文档漂移与私有信息泄露的源头（通用治理条文锁在本机 gitignore 文件里、本机独有的运维细节却公开发布在入库文件中——双重倒置）。

## 决策

仓库要向 agent 传达的内容恰为三类，术语定名如下，「入口文档」一词作废：

| 类别 | 本质 | 生效范围 | 生产方式 |
|------|------|----------|----------|
| **项目说明书** | 这是什么仓 / 结构 / 命令 / 模块索引 | 任何 clone | 机器可再生（sync-docs / gen-agents-md） |
| **治理契约** | 改这个仓必须守的规矩（铁律 / 沉淀纪律 / 治理流程 / 工单类型） | 任何 clone——谁改这个仓都该守 | 人写，治理变更流程管控 |
| **本机运维簿** | 这台机器上怎么部署 / 脚本路径 / 日志位置 / 告警渠道 / 事故史 | 仅本机——别的机器没有这些脚本和路径 | 人写，本机维护 |

## 判别轴

一个问题定归属：**这段内容对「任何 clone 这个仓的人」有效力，还是只对「这台机器」有效力？** 该轴（「生效范围」）连同三个类名进根 `CONTEXT.md` 词表。

## 推论

- 治理契约锁在 gitignore 文件 = 约束自愿放弃（对任何非本机 clone 自动失效）。
- 本机运维簿内容对局外人可见不是特性，是泄露；它跑不了本机的脚本，拿它毫无意义。
- 治理契约是纯规则文本（无路径、无凭证），公开无泄露；票号引用可清洗，规则本身是公共仓该有的工程文化展示。
