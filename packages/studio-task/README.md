# @agent-studio/task

Task CLI for agent-studio.

## Commands

| Command | Usage |
|---------|-------|
| `queue` | View queue `--company=<id> [--status=<pending/running/completed>]` |
| `run` | Execute task `--task=<id>` |
| `retry` | Retry failed `--task=<id>` |
| `clean` | Clean completed `--company=<id> --days=<n>` |
